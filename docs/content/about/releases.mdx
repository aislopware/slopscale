---
title: "Releases"
description: "Where slopscale releases are published: binaries and Debian packages on GitHub releases, container images on GHCR, and an Atom feed to follow."
---

All slopscale releases are available on the [GitHub release page](https://github.com/aislopware/slopscale/releases). Those
releases are available as binaries for various platforms and architectures, packages for Debian based systems and source
code archives. Container images are available on the
[GitHub Container Registry](https://github.com/aislopware/slopscale/pkgs/container/slopscale).

An Atom/RSS feed of slopscale releases is available [here](https://github.com/aislopware/slopscale/releases.atom).
