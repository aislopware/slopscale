We aim to support the [**last 10 releases** of the Tailscale client](https://tailscale.com/changelog#client) on all
provided operating systems and platforms. Some platforms might require additional configuration to connect with
slopscale.

| OS      | Supports slopscale                                                                                    |
| ------- | ----------------------------------------------------------------------------------------------------- |
| Linux   | Yes                                                                                                   |
| OpenBSD | Yes                                                                                                   |
| FreeBSD | Yes                                                                                                   |
| Windows | Yes (see [docs](/usage/connect/windows) and `/windows` on your slopscale for more information)   |
| Android | Yes (see [docs](/usage/connect/android) for more information)                                    |
| macOS   | Yes (see [docs](/usage/connect/apple#macos) and `/apple` on your slopscale for more information) |
| iOS     | Yes (see [docs](/usage/connect/apple#ios) and `/apple` on your slopscale for more information)   |
| tvOS    | Yes (see [docs](/usage/connect/apple#tvos) and `/apple` on your slopscale for more information)  |
